# Pedra, Papel ou Tesoura

Um jogo simples de **Pedra, Papel e Tesoura**, feito em JavaScript, HTML e CSS durante um curso de JavaScript.

🔗 **Jogue online:** [siqueira2009.github.io/ppt](https://siqueira2009.github.io/ppt/)

## 📋 Sobre o projeto

O jogador escolhe entre pedra, papel ou tesoura, enquanto o "Inimigo" (computador) faz sua escolha. Ao confirmar a jogada, o resultado é exibido na tela junto com o placar atualizado, podendo o jogador recomeçar a partida quando quiser.

## 🛠️ Tecnologias utilizadas

- **HTML5** - estrutura da página
- **CSS3** - estilização e responsividade (`style.css` e `responsive.css`)
- **JavaScript** - lógica do jogo (`script.js`)
- **[Twemoji](https://github.com/twitter/twemoji)** - renderização dos emojis utilizados nas jogadas

## 📁 Estrutura do repositório

```
ppt/
├── favicon.svg        # Ícone do site

├── responsive.css     # Estilos responsivos
```

## 🚀 Como executar localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/siqueira2009/ppt.git
   ```
2. Entre na pasta do projeto:
   ```bash
   cd ppt
   ```
3. Abra o arquivo `index.html` no seu navegador de preferência.

> Não é necessário nenhum servidor ou instalação de dependências - é um projeto front-end puro (HTML, CSS e JS).

## 🎮 Como jogar

1. Escolha uma das opções: ✊ (pedra), 🖐️ (papel) ou ✌️ (tesoura).
2. Clique no botão **OK!** para confirmar a jogada.
3. O resultado da partida e o placar serão exibidos automaticamente.
4. Clique em **Recomeçar** para jogar novamente.

## 📱 Responsividade

O jogo possui um aviso de "Site indisponível" para telas muito pequenas, garantindo uma melhor experiência apenas em dispositivos com espaço suficiente para exibir o tabuleiro de jogo.
